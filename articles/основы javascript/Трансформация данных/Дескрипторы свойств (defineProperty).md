# Дескрипторы свойств (defineProperty)

## БЫСТРЫЙ СТАРТ

*   **Дескрипторы свойств** — это скрытые системные флаги-настройки, которые определяют поведение, видимость и права доступа к каждому конкретному свойству объекта.
*   **`Object.defineProperty(obj, prop, descriptor)`** — статический метод, позволяющий создать новое свойство или изменить настройки существующего, явно задавая системные флаги.
*   **Основные флаги (атрибуты):**
    *   `writable` — разрешает изменение значения свойства (если `false`, свойство доступно только для чтения).
    *   `enumerable` — разрешает отображение свойства в циклах `for...in` и методах вроде `Object.keys()` (если `false`, свойство скрыто).
    *   `configurable` — разрешает удаление свойства и изменение настроек его дескрипторов в будущем.
*   **Используйте для:** создания защищенных системных настроек, инкапсуляции служебных полей и реализации вычисляемых свойств (геттеров и сеттеров).
*   **Не смешивайте типы:** Дескриптор данных (`value`, `writable`) и дескриптор доступа (`get`, `set`) взаимно исключают друг друга. Попытка объявить их вместе вызовет критическую ошибку `TypeError`.

## ПРАКТИЧЕСКИЕ ШАБЛОНЫ ДЛЯ КОПИРОВАНИЯ

### Шаблон 1: Объявление свойства «Только для чтения» (ReadOnly)
*   **Назначение:** Добавление в объект защищенного ключа (например, уникального ID), значение которого невозможно переписать или удалить из внешнего кода.

```typescript
export interface TargetPayload {
  identifier: string;
  statePayload: string;
}

export function createSecureRecord(uid: string, initialData: string): TargetPayload {
  const secureObject = {} as TargetPayload;

  // Объявляем строго защищенное свойство identifier
  Object.defineProperty(secureObject, "identifier", {
    value: uid,
    writable: false,      // Запрещаем перезапись значения
    enumerable: true,     // Свойство будет видно при переборе и в JSON
    configurable: false   // Запрещаем удаление свойства и изменение этих флагов в будущем
  });

  // Обычное свойство, открытое для модификаций
  secureObject.statePayload = initialData;

  return secureObject;
}
```

### Шаблон 2: Скрытие служебных свойств от перебора (Non-Enumerable)
*   **Назначение:** Добавление в объект служебных метаданных, которые не должны отображаться в циклах `for...in`, не должны копироваться при spread-копировании и не попадают в итоговый JSON при отправке на сервер.

```typescript
export interface ConfigOptions {
  activeUrl: string;
  secretHash: string; // Служебное скрытое свойство
}

export function createConfigWithHiddenToken(url: string, hash: string): ConfigOptions {
  const config = { activeUrl: url } as ConfigOptions;

  // Свойство secretHash будет физически существовать в объекте, но станет невидимым для обхода
  Object.defineProperty(config, "secretHash", {
    value: hash,
    writable: true,
    enumerable: false,   // Скрываем свойство от циклов и Object.keys()
    configurable: true
  });

  return config;
}
```

### Шаблон 3: Вычисляемые свойства (Геттеры и Сеттеры в дескрипторах)
*   **Назначение:** Реализация реактивной логики (например, валидация данных при записи или форматирование при чтении) на уровне дескрипторов доступа.

```typescript
export interface DataState {
  rawScore: number;
}

export function createReactiveState(): DataState {
  const stateContainer = {} as DataState;
  let internalValue = 0; // Локальный изолированный буфер для хранения значения

  // Описываем дескриптор доступа (Accessor Descriptor)
  Object.defineProperty(stateContainer, "rawScore", {
    // Вызывается автоматически при чтении свойства stateContainer.rawScore
    get() {
      console.log("Логирование: Чтение значения rawScore");
      return internalValue;
    },
    // Вызывается автоматически при записи свойства stateContainer.rawScore = value
    set(newValue: number) {
      if (newValue < 0) {
        console.warn("Предупреждение: Значение не может быть отрицательным.");
        return; // Блокируем некорректную запись
      }
      console.log(`Логирование: Успешная запись значения rawScore: ${newValue}`);
      internalValue = newValue; // Пишем значение в локальный буфер
    },
    enumerable: true,
    configurable: true
  });

  return stateContainer;
}
```

### Шаблон 4: Контроль расширения структуры объекта (Seal и Freeze)
*   **Назначение:** Быстрая блокировка динамического изменения структуры всего объекта на системном уровне.

```typescript
export interface TemporaryResult {
  status: string;
}

export function secureResultStructure(result: TemporaryResult): TemporaryResult {
  // 1. Ограничение на добавление новых свойств (Object.preventExtensions)
  // Новые ключи добавить нельзя, но старые можно изменять и удалять

  // 2. Запечатывание объекта (Object.seal)
  // Запрещает добавлять новые свойства, удалять старые или менять их дескрипторы.
  // Изменять значения существующих свойств по-прежнему разрешено.
  const sealed = Object.seal(result);

  // 3. Полная заморозка объекта (Object.freeze)
  // Полный запрет любых изменений: нельзя добавлять, удалять, перезаписывать свойства.
  // Все дескрипторы автоматически переходят в configurable: false, writable: false.
  const frozen = Object.freeze(sealed);

  return frozen;
}
```

## ГЛУБОКОЕ ПОГРУЖЕНИЕ

### 1. Системные различия между дескрипторами данных и дескрипторами доступа
В спецификации ECMAScript дескрипторы свойств строго делятся на два взаимоисключающих типа:

#### А. Дескрипторы данных (Data Descriptors)
Описывают свойство, которое хранит конкретное физическое значение. Они могут содержать только следующие ключи:
*   `value` — непосредственно данные (любой тип JS).
*   `writable` — булево разрешение на изменение значения.
*   `enumerable` — видимость свойства при итерациях.
*   `configurable` — право на удаление свойства и изменение его флагов.

#### Б. Дескрипторы доступа (Accessor Descriptors)
Описывают свойства, у которых нет физической ячейки данных, а чтение и запись делегируются функциям. Они могут содержать только следующие ключи:
*   `get` — функция без аргументов, возвращающая значение при чтении.
*   `set` — функция с одним аргументом, выполняющая запись.
*   `enumerable` — видимость свойства.
*   `configurable` — право на удаление и изменение флагов.

**Физика несовместимости:**
Вы не можете объявить в дескрипторе одновременно ключи `value` и `get` (или `writable` и `set`). Объект в памяти V8 не может одновременно хранить сырые данные и вычислять их через функции. Попытка смешать эти ключи вызовет немедленную ошибку `TypeError` на этапе парсинга.

### 2. Сравнение уровней защиты объектов в куче
JavaScript предоставляет три статических метода для ступенчатого ограничения мутабельности объектов:

| Метод | Можно добавлять свойства? | Можно удалять свойства? | Можно изменять значения? | Меняет ли флаги дескрипторов? |
| :--- | :---: | :---: | :---: | :---: |
| `Object.preventExtensions(obj)` | **Нет** | Да | Да | Нет |
| `Object.seal(obj)` | **Нет** | **Нет** | Да | Да (делает все `configurable: false`) |
| `Object.freeze(obj)` | **Нет** | **Нет** | **Нет** | Да (`configurable: false`, `writable: false`) |

Эти методы изменяют внутренние системные метаданные объекта на уровне движка V8. При нарушении этих правил в строгом режиме `"use strict"` (который в TypeScript включен по умолчанию) рантайм незамедлительно выбросит критическое исключение `TypeError`.

### 3. Детальный пошаговый разбор выполнения шаблона 3
1.  **Создание буфера:** Вызывается функция `createReactiveState()`. В замыкании создается переменная `internalValue = 0`.
2.  **Объявление дескриптора:** Метод `Object.defineProperty` настраивает вычисляемое свойство `rawScore` на объекте `stateContainer`.
3.  **Попытка записи:** Выполняется строчка `stateContainer.rawScore = 15`. Движок V8 видит, что свойство имеет дескриптор доступа. Запись значения `15` в ячейку памяти не происходит напрямую. Вместо этого V8 приостанавливает поток, находит функцию `set` и вызывает ее, передавая `15` в качестве аргумента `newValue`.
4.  **Проверка условий:** Внутри функции `set` выполняется валидация `newValue < 0`. Проверка успешна. Выполняется строчка `internalValue = 15`, обновляя изолированную переменную в куче.
5.  **Чтение значения:** Выполняется чтение `console.log(stateContainer.rawScore)`. Движок V8 перехватывает обращение, находит функцию `get` и запускает ее. Функция считывает актуальное значение `internalValue` из замыкания и возвращает его.

### 4. Типичные ошибки и их решение

*   **Ошибка 1: Смешивание Data и Accessor дескрипторов**
    *   *Проблема:* Разработчик пытается создать свойство-геттер, но указывает для него дефолтное значение через `value` или флаг `writable`. Программа аварийно завершает работу с ошибкой `TypeError: Invalid property descriptor. Cannot both specify accessors and a value or writable attribute`.
    *   *Решение:* Четко разделяйте типы дескрипторов. Если используете `get` или `set`, полностью удаляйте ключи `value` и `writable`.

```typescript
// ПЛОХО (Смешивание типов вызовет падение рантайма)
export function defineBadProperty(obj: any): void {
  Object.defineProperty(obj, "prop", {
    get() { return "data"; },
    value: "bad_value" // ! TypeError: Cannot both specify accessors and a value
  });
}
```

*   **Ошибка 2: Попытка перезаписать или настроить некорректно объявленное свойство**
    *   *Проблема:* Вызов `Object.defineProperty` на свойстве, которое ранее было объявлено со значением `configurable: false`. Любая попытка изменить его дескрипторы или удалить свойство вызовет ошибку `TypeError: Cannot redefine property`.
    *   *Решение:* Если структура объекта или его свойства должны динамически перенастраиваться во время выполнения программы, всегда объявляйте дескрипторы с флагом `configurable: true`.

*   **Ошибка 3: Ограниченность поверхностной заморозки `Object.freeze()`**
    *   *Проблема:* Разработчик вызывает `Object.freeze(config)` на сложном объекте со вложенными структурами и ожидает полной иммутабельности. Однако вложенные объекты по-прежнему остаются доступными для изменений в куче.
    *   *Причина:* `Object.freeze()` замораживает свойства только первого уровня вложенности (поверхностная заморозка).
    *   *Решение:* Для полной защиты глубоких структур реализуйте рекурсивную функцию глубокой заморозки (Deep Freeze).

```typescript
// Реализация безопасной глубокой заморозки сложного объекта
export function deepFreeze<T extends object>(obj: T): T {
  // Находим все собственные свойства объекта (включая неперечисляемые)
  const propNames = Reflect.ownKeys(obj);

  for (const name of propNames) {
    const value = (obj as any)[name];
    // Если свойство является сложным объектом, рекурсивно замораживаем его
    if (value && typeof value === "object") {
      deepFreeze(value);
    }
  }

  // Замораживаем текущий уровень объекта
  return Object.freeze(obj);
}
```
