# Преобразование объекта в массив (Object methods)

## БЫСТРЫЙ СТАРТ

*   **`Object.keys(obj)`** — возвращает массив строковых ключей (имен свойств) объекта.
*   **`Object.values(obj)`** — возвращает массив значений этих свойств.
*   **`Object.entries(obj)`** — возвращает массив пар `[ключ, значение]`, представляющий свойства объекта.
*   **`Object.fromEntries(iterable)`** — выполняет обратную операцию: собирает из массива пар (или из `Map`) полноценный объект.
*   **Используйте их для:** итерации по свойствам объектов с помощью мощных методов массивов (`.map()`, `.filter()`, `.reduce()`) и быстрой фильтрации/трансформации ключей или значений.
*   **Помните об ограничениях:** Эти методы обходят только собственные перечисляемые свойства объекта (`enumerable: true`) и полностью **игнорируют свойства-символы (`Symbol`)** и свойства из цепочки прототипов.

## ПРАКТИЧЕСКИЕ ШАБЛОНЫ ДЛЯ КОПИРОВАНИЯ

### Шаблон 1: Сбор и валидация ключей через `Object.keys()`
*   **Назначение:** Быстрое получение списка названий всех свойств объекта для валидации структуры данных или проверки на пустоту.

```typescript
export interface ConfigOptions {
  activeUrl: string;
  timeoutLimit: number;
}

export function validateRequiredKeys(configs: ConfigOptions): boolean {
  // Получаем плоский массив всех ключей объекта
  const configKeys = Object.keys(configs);

  // Быстрая проверка на пустоту объекта
  if (configKeys.length === 0) {
    return false;
  }

  // Проверяем, содержит ли объект все обязательные ключи
  const requiredKeys = ["activeUrl", "timeoutLimit"];
  return requiredKeys.every(key => configKeys.includes(key));
}
```

---

### Шаблон 2: Агрегация значений объекта через `Object.values()`
*   **Назначение:** Подсчет сумм, средних или сбор значений всех полей объекта-словаря без использования циклов.

```typescript
export type TargetPayload = Record<string, number>;

export function sumAllValues(payload: TargetPayload): number {
  // Извлекаем массив только числовых значений полей объекта
  const numericValues = Object.values(payload);

  // Быстро суммируем значения с помощью метода reduce
  return numericValues.reduce((sum, current) => sum + current, 0);
}
```

### Шаблон 3: Фильтрация и трансформация объекта через `Object.entries()` и `Object.fromEntries()`
*   **Назначение:** Реализация иммутабельной фильтрации полей объекта (например, удаление пустых значений) за один сквозной проход.

```typescript
export interface DataState {
  id: string;
  payload: string | null;
  timestamp: number | null;
}

export function removeNullValues(state: DataState): Partial<DataState> {
  // 1. Преобразуем объект в массив пар [ключ, значение]
  const stateEntries = Object.entries(state);

  // 2. Фильтруем пары, отсекая те, у которых значение равно null
  const filteredEntries = stateEntries.filter(([_, value]) => value !== null);

  // 3. Собираем массив пар обратно в новый иммутабельный объект
  return Object.fromEntries(filteredEntries);
}
```

## ГЛУБОКОЕ ПОГРУЖЕНИЕ

### 1. Как методы Object.keys/values/entries устроены под капотом движка V8
Объекты в JS под капотом движка V8 могут быть представлены в виде оптимизированных структур (Fast Properties с Hidden Classes) или в виде классических словарей (Dictionary Mode). Вызов `Object.keys/values/entries` заставляет V8 выполнить операцию экспорта внутренней структуры свойств в плоский индексированный массив.

#### Спецификация порядка обхода свойств (Property Traversal Order):
Порядок ключей в возвращаемом массиве жестко зафиксирован в спецификации ECMAScript и состоит из трех последовательных шагов:
1.  **Целочисленные ключи (Integer Indices):** Все ключи, которые могут быть преобразованы в целые числа (например, `"1"`, `"42"`), сортируются строго **в порядке возрастания числовых значений**.
2.  **Строковые ключи:** Все остальные строковые свойства сортируются строго **в хронологическом порядке их физического добавления (вставки)** в объект.
3.  **Свойства-символы (Symbol keys):** Игнорируются методами `Object.keys/values/entries`. Для их извлечения требуется использовать метод `Object.getOwnPropertySymbols()`.

### 2. Спецификация и особенности работы `Object.fromEntries()`
Метод `Object.fromEntries()` (стандарт ES2019) выполняет операцию, обратную `.entries()`. Он принимает на вход любой **итерируемый объект (Iterable)**, возвращающий пары вида `[key, value]`.

Особенности рантайма:
*   В качестве аргумента метод принимает не только обычные двумерные массивы, но и коллекции `Map` (например, `Object.fromEntries(myMap)` мгновенно конвертирует Map в плоский объект).
*   Если в итерируемой структуре встречаются дубликаты ключей (например, `[["a", 1], ["a", 2]]`), V8 не выбросит ошибку. Метод просто перезапишет значение ключа последним встреченным значением по ходу итерации.

### 3. Детальный пошаговый разбор выполнения шаблона 3
1.  **Преобразование в пары:** Вызывается `removeNullValues(state)`. Метод `Object.entries(state)` считывает собственные перечисляемые свойства объекта `state`. На выходе создается массив: `[["id", "id_1"], ["payload", null], ["timestamp", 171717]]`.
2.  **Фильтрация:** Запускается метод `.filter()`. Каждая пара деструктурируется прямо в аргументах колбэка на `key` и `value`. Пара `["payload", null]` отсеивается, так как ее значение `null`. Массив сокращается до: `[["id", "id_1"], ["timestamp", 171717]]`.
3.  **Сборка объекта:** Метод `Object.fromEntries(filteredEntries)` выделяет память под новый пустой объект в куче.
4.  **Запись по ключам:** Движок итерируется по парам и последовательно записывает свойства в созданный объект: сначала `id: "id_1"`, затем `timestamp: 171717`.
5.  **Возврат:** Новый иммутабельный объект возвращается из функции.

### 4. Типичные ошибки и их решение

*   **Ошибка 1: Иллюзия сохранения хронологического порядка числовых ключей**
    *   *Проблема:* Разработчик создает объект-карту, где ключами являются ID (например, номера постов), и ожидает, что `Object.keys` вернет их в порядке вставки. Код ломает логику отображения, так как V8 автоматически сортирует числовые ключи по возрастанию.
    *   *Решение:* Если порядок вставки критически важен, а ключи являются числами, используйте коллекцию `Map` вместо обычного `Object`. В `Map` порядок ключей всегда гарантированно соответствует порядку их вставки.

```typescript
// ПЛОХО (V8 автоматически отсортирует ключи по возрастанию: "2", "10", "100")
export function logBadOrder(): void {
  const mapObj = { "100": "A", "2": "B", "10": "C" };
  console.log(Object.keys(mapObj)); // Вывод: ["2", "10", "100"] (Порядок вставки нарушен!)
}
```

*   **Ошибка 2: Вызов методов `Object.keys/values/entries` на значениях `null` или `undefined`**
    *   *Проблема:* Попытка выполнить `Object.keys(data)` для объекта `data`, который пришел с сервера как `null` или `undefined`. Программа падает с критической ошибкой `TypeError: Cannot convert undefined or null to object`.
    *   *Решение:* Оборачивайте вызовы методов в логические проверки или передавайте пустой объект в качестве резервного значения через оператор `??`.

```typescript
// ПЛОХО (Вызовет падение, если data придет пустой)
export function getKeysUnsafe(data: any): string[] {
  return Object.keys(data); // ! TypeError при null/undefined
}

// ХОРОШО (Безопасная обработка через оператор нулевого слияния)
export function getKeysSafe(data: any): string[] {
  return Object.keys(data ?? {}); // Передаем пустой объект при отсутствии данных
}
```

*   **Ошибка 3: Потеря неперечисляемых (Non-enumerable) свойств и символов**
    *   *Проблема:* Разработчик пытается скопировать объект через `Object.fromEntries(Object.entries(obj))`, но обнаруживает, что свойства-символы (`Symbol`) и системные свойства, объявленные с флагом `enumerable: false`, полностью исчезли из копии.
    *   *Решение:* Помните, что данные методы предназначены только для работы с публичными перечисляемыми свойствами. Для полного извлечения всех ключей (включая неперечисляемые и символы) используйте метод `Reflect.ownKeys(obj)`.
