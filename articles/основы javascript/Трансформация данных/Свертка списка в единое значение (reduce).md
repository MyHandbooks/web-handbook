# Свертка списка в единое значение (reduce)

## БЫСТРЫЙ СТАРТ

*   **`Array.prototype.reduce(callback, [initialValue])`** — встроенный метод массивов, который последовательно обрабатывает каждый элемент списка, накапливая результат в переменной-аккумуляторе, и возвращает **одно единое результирующее значение** произвольного типа.
*   **Гибкость:** Этот метод является самым мощным инструментом трансформации данных. С его помощью можно эмулировать работу методов `.map()`, `.filter()`, `.find()`, собирать из массивов сложные хэш-таблицы или вычислять агрегированные показатели.
*   **Используйте его для:** группировки объектов по ключу, подсчета сумм, средних значений или сбора сложных структур данных за один проход массива.
*   **Всегда указывайте `initialValue` (начальное значение):** Если этого не сделать, на пустом массиве метод выбросит критическую ошибку `TypeError`, а при непустом массиве первым аккумулятором станет первый элемент списка, что часто приводит к багам типизации.

## ПРАКТИЧЕСКИЕ ШАБЛОНЫ ДЛЯ КОПИРОВАНИЯ

### Шаблон 1: Агрегация числовых показателей (Сумма и Среднее значение)
*   **Назначение:** Быстрый подсчет суммарной стоимости или среднего арифметического по конкретному числовому полю массива объектов.

```typescript
export interface DataState {
  id: string;
  metricValue: number;
}

export function calculateAverageMetric(items: DataState[]): number {
  if (items.length === 0) return 0;

  // Метод reduce аккумулирует сумму числовых значений
  const totalSum = items.reduce((accumulator, item): number => {
    // Прибавляем текущее значение к накопленной сумме
    return accumulator + item.metricValue;
  }, 0); // 0 — строго обязательное начальное значение аккумулятора

  return totalSum / items.length; // вычисляем среднее арифметическое
}
```

### Шаблон 2: Группировка массива объектов в ассоциативную карту (Grouping/GroupingBy)
*   **Назначение:** Преобразование плоского списка объектов в объект-словарь, сгруппированный по значению определенного свойства (аналог SQL GROUP BY).

```typescript
export interface ConfigOptions {
  identifier: string;
  categoryGroup: string;
  payload: string;
}

export type GroupedConfigs = Record<string, ConfigOptions[]>;

export function groupConfigsByCategory(configs: ConfigOptions[]): GroupedConfigs {
  // Накапливаем результат в объекте типа GroupedConfigs
  return configs.reduce((accumulator, config): GroupedConfigs => {
    const key = config.categoryGroup;

    // Если группы с таким ключом еще нет в аккумуляторе, инициализируем ее пустым массивом
    if (!accumulator[key]) {
      accumulator[key] = [];
    }

    // Добавляем текущую конфигурацию в соответствующую группу
    accumulator[key].push(config);

    return accumulator; // Обязательно возвращаем измененный аккумулятор для следующего шага
  }, {} as GroupedConfigs); // Инициализируем аккумулятор пустым объектом
}
```

### Шаблон 3: Оптимизированная фильтрация + маппинг за один проход (O(N))
*   **Назначение:** Трансформация данных с одновременным отсеиванием невалидных значений. Позволяет избежать вызова цепочки `.filter().map()`, которая делает два полных прохода по массиву в памяти.

```typescript
export interface SourceModel {
  uid: string;
  isActive: boolean;
  score: number;
}

export interface ViewModel {
  id: string;
  doubledScore: number;
}

export function filterAndTransformModels(models: SourceModel[]): ViewModel[] {
  // Накапливаем только валидные и трансформированные объекты в новом массиве
  return models.reduce((accumulator, model): ViewModel[] => {
    if (model.isActive && model.score > 0) {
      // Если объект прошел валидацию, трансформируем его и добавляем в массив-аккумулятор
      accumulator.push({
        id: model.uid,
        doubledScore: model.score * 2
      });
    }
    return accumulator; // Пропускаем неактивные объекты, возвращая неизмененный аккумулятор
  }, [] as ViewModel[]); // Инициализируем аккумулятор пустым массивом
}
```

### Шаблон 4: Преобразование списка в хэш-таблицу `Map`
*   **Назначение:** Быстрое индексирование массива объектов по уникальному ключу для обеспечения мгновенного поиска O(1) в будущем.

```typescript
export interface TemporaryResult {
  uid: string;
  payloadData: string;
}

export function indexResultsToMap(results: TemporaryResult[]): Map<string, TemporaryResult> {
  // Сворачиваем массив в стандартный объект Map
  return results.reduce((accumulator, result): Map<string, TemporaryResult> => {
    // Записываем объект в карту под его уникальным ключом
    accumulator.set(result.uid, result);
    return accumulator;
  }, new Map<string, TemporaryResult>()); // Инициализируем аккумулятор чистым инстансом Map
}
```

## ГЛУБОКОЕ ПОГРУЖЕНИЕ

### 1. Как метод `Array.prototype.reduce()` устроен на уровне спецификации ECMAScript
Метод `.reduce()` реализует классический паттерн свертки (Fold) из функционального программирования. 

Алгоритм его работы на низком уровне спецификации:
1.  **Определение начального значения:** Движок считывает второй аргумент `initialValue`.
    *   *Сценарий А (Значение передано):* Переменная-аккумулятор `accumulator` инициализируется этим значением. Цикл итераций начинается с индекса `0`.
    *   *Сценарий Б (Значение НЕ передано):* Движок берет в качестве стартового аккумулятора **первый физически существующий элемент массива** (с индексом `0`). Цикл итераций принудительно начинается со следующего элемента (с индекса `1`).
2.  **Пошаговый обход:** На каждом шаге вызывается коллбэк, который принимает четыре аргумента: `accumulator` (результат предыдущего шага), `currentValue` (текущий элемент), `index` и ссылку на оригинальный `array`.
3.  **Перезапись аккумулятора:** Возвращаемое значение из колбэка становится новым значением `accumulator` для следующей итерации.
4.  **Разреженные массивы:** Пустые ячейки (дыры) полностью игнорируются. Если у разреженного массива нет `initialValue` и его первые ячейки пусты, движок будет искать первый заполненный индекс, чтобы сделать его стартовым аккумулятором.

### 2. Физика работы свертки в V8 и критическая важность `initialValue`
Непередача начального значения `initialValue` — одна из главных причин скрытых runtime-ошибок.

#### А. Риск падения на пустом массиве
Если массив оказывается пустым (например, с сервера пришел пустой список `[]`) и вы вызвали `.reduce()` без `initialValue`, движку V8 нечего взять в качестве стартового аккумулятора. Спецификация обязывает в этом случае немедленно прервать выполнение и выбросить критическую ошибку `TypeError: Reduce of empty array with no initial value`. Наличие `initialValue` (например, `0` или `[]`) страхует приложение от падения: метод просто вернет это значение без запуска цикла.

#### Б. Оптимизация скрытых классов (Hidden Classes) в V8
Когда вы передаете `initialValue` (например, пустой объект `{}`), движок V8 сразу создает под него оптимизированную структуру данных с фиксированным скрытым классом (Shape). Если внутри колбэка вы правильно возвращаете этот объект, структура памяти остается стабильной, и JIT-компилятор оптимизирует доступ к свойствам. 
Если вы опустили `initialValue`, типы данных на первом шаге (свойство индекса `0`) и последующих шагах могут различаться, что приведет к деоптимизации кода движком и замедлению вычислений.

### 3. Детальный пошаговый разбор выполнения шаблона 2
1.  **Выделение памяти:** Вызывается функция `groupConfigsByCategory(configs)`. Метод `reduce` инициализирует аккумулятор `accumulator` пустым объектом `{}` (благодаря переданному вторым аргументом литералу `{}`).
2.  **Итерация 1:** Обрабатывается объект `configs[0]` (категория `"Драма"`). Ключ `"Драма"` отсутствует в `accumulator`. Движок создает пустой массив `accumulator["Драма"] = []`. Выполняется метод `.push()`. Объект добавляется в массив. Возвращается измененный `accumulator` (который теперь равен `{ "Драма": [configs[0]] }`).
3.  **Итерация 2:** Обрабатывается объект `configs[1]` (категория `"Боевик"`). Инициализируется пустой массив `accumulator["Боевик"] = []`. Объект добавляется. Возвращается измененный аккумулятор.
4.  **Итерация 3:** Обрабатывается объект `configs[2]` (категория `"Драма"`). Ключ `"Драма"` уже существует в аккумуляторе. Инициализация пропускается. Выполняется метод `.push()`. Объект добавляется в существующий массив.
5.  **Завершение:** После обхода всех элементов итоговый объект-словарь возвращается из функции.

### 4. Типичные ошибки и их решение

*   **Ошибка 1: Избыточный spread-оператор аккумулятора внутри цикла (Катастрофа производительности O(N^2))**
    *   *Проблема:* Разработчик пытается писать в модном иммутабельном стиле и на каждой итерации копирует аккумулятор через spread-оператор: `return { ...acc, [key]: value }`. На больших массивах (более 1000 элементов) этот код начинает работать критически медленно и может полностью повесить вкладку.
    *   *Причина:* Spread-оператор `{ ...acc }` заставляет движок V8 на *каждой* итерации цикла полностью копировать все ранее собранные свойства в новый объект в куче. Сложность алгоритма возрастает с линейной O(N) до квадратичной O(N^2).
    *   *Решение:* Мутируйте сам локальный объект аккумулятора внутри колбэка и возвращайте его. Это абсолютно безопасно, так как аккумулятор — это изолированный объект, созданный специально для этого вызова `reduce` (мутация локального аккумулятора не нарушает внешнюю иммутабельность).

```typescript
// ПЛОХО (Квадратичная сложность O(N^2) уничтожит производительность на больших данных)
export function processSlowReduce(items: ConfigOptions[]): GroupedConfigs {
  return items.reduce((acc, curr) => {
    return {
      ...acc, // ! Копирует весь объект заново на каждом шаге цикла!
      [curr.categoryGroup]: [...(acc[curr.categoryGroup] || []), curr] // ! Двойное копирование!
    };
  }, {} as GroupedConfigs);
}

// ХОРОШО (Чистая линейная сложность O(N) за счет мутации локального аккумулятора)
export function processFastReduce(items: ConfigOptions[]): GroupedConfigs {
  return items.reduce((acc, curr) => {
    const key = curr.categoryGroup;
    if (!acc[key]) acc[key] = [];
    acc[key].push(curr); // Быстрая мутация локального буфера
    return acc; // Возвращаем ссылку на тот же объект
  }, {} as GroupedConfigs);
}
```

*   **Ошибка 2: Невозвращение аккумулятора из функции-коллбэка**
    *   *Проблема:* Разработчик выполняет операции над аккумулятором внутри колбэка, но забывает написать ключевое слово `return acc` в конце функции. На следующей итерации программа падает с ошибкой `TypeError: Cannot read properties of undefined`.
    *   *Решение:* Результат работы колбэка всегда становится аккумулятором для следующего шага. Вы обязаны явно возвращать аккумулятор на каждой итерации.

```typescript
// ПЛОХО (На второй итерации acc станет равен undefined и вызовет падение)
export function getSumUnsafe(items: DataState[]): number {
  return items.reduce((acc, curr) => {
    acc + curr.metricValue; // ! Ошибка: Забыли написать return!
  }, 0);
}
```

*   **Ошибка 3: Ошибка несоответствия типов в TypeScript при отсутствии `initialValue`**
    *   *Проблема:* Вы пытаетесь свернуть массив объектов в число (сумму), но не указали `initialValue` равным `0`. TypeScript начинает ругаться, что невозможно сложить объект и число.
    *   *Причина:* Без `initialValue` типом аккумулятора по умолчанию становится тип элемента массива. Вы пытаетесь сложить первый объект с числовым свойством второго объекта.
    *   *Решение:* Всегда явно указывайте `initialValue` нужного результирующего типа.
