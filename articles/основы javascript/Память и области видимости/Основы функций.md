# Основы функций

## БЫСТРЫЙ СТАРТ

*   **Объекты первого класса (First-Class Citizens)** — в JavaScript функции ведут себя как обычные значения: их можно присваивать переменным, передавать аргументами в другие функции и возвращать из них.
*   **Function Declaration (Декларация)** — объявление функции, которое полностью поднимается (hoisted) в начало области видимости на этапе компиляции. Ее можно вызывать выше строки физического объявления.
*   **Function Expression (Выражение)** — анонимная или именованная функция, записанная в переменную. Подчиняется стандартным правилам инициализации переменных и не может быть вызвана до своей строчки в коде.
*   **Стрелочные функции (Arrow Functions)** — компактный синтаксис. Они не имеют своего контекста `this` (заимствуют его из родительского окружения), у них нет встроенного объекта `arguments` и их нельзя вызывать через оператор `new` (нет метода <code>&#91;&#91;Construct&#93;&#93;</code>).

## ПРАКТИЧЕСКИЕ ШАБЛОНЫ ДЛЯ КОПИРОВАНИЯ

### Шаблон 1: Чистая функция с иммутабельной трансформацией данных
*   **Назначение:** Безопасное добавление элемента в массив внутри объекта без прямой мутации исходного состояния (Side Effects).

```javascript
// Исходный объект данных (например, состояние корзины покупок)
const initialCartState = {
  items: ["Клавиатура"],
  totalPrice: 4000
};

// Чистая функция (Pure Function) без побочных эффектов
function addNewItemToCart(cart, newItem, price) {
  // ПЛОХО: cart.items.push(newItem) мутирует исходный объект по ссылке
  // ХОРОШО: Возвращаем новую поверхностную копию объекта через spread-оператор
  return {
    ...cart, // Распаковываем старые свойства корзины
    items: [...cart.items, newItem], // Копируем массив и точечно добавляем новый элемент
    totalPrice: cart.totalPrice + price // Вычисляем новое значение цены
  };
}

// Выполняем трансформацию
const updatedCartState = addNewItemToCart(initialCartState, "Мышь", 1500);

// Исходное состояние в памяти осталось нетронутым
console.log(initialCartState); // { items: ["Клавиатура"], totalPrice: 4000 }
console.log(updatedCartState); // { items: ["Клавиатура", "Мышь"], totalPrice: 5500 }
```

### Шаблон 2: Гибкая обработка произвольного числа аргументов
*   **Назначение:** Создание функции расчета со сбором динамических аргументов в единый массив с помощью rest-параметров (`...`).

```javascript
// Функция вычисляет сумму с учетом переменного налога
// rest-параметр ...prices ВСЕГДА должен идти последним в списке аргументов
const calculateInvoiceWithTax = (taxRate, ...prices) => {
  // prices автоматически собирается в полноценный итерируемый массив
  const netSum = prices.reduce((acc, current) => acc + current, 0);
  
  // Возвращаем итоговую сумму с накруткой налога
  return netSum + (netSum * taxRate);
};

// Вызов функции.prices принимает список чисел произвольной длины
const totalWithTax = calculateInvoiceWithTax(0.20, 1000, 2000, 3000);
console.log(`[СЧЕТ] Итого к оплате: ${totalWithTax}`); // 7200
```

## ГЛУБОКОЕ ПОГРУЖЕНИЕ

### 1. Функции как объекты первого класса (First-Class Citizens) в архитектуре V8
В архитектуре движка V8 функция не является примитивным типом. Под капотом функция — это специализированный объект, унаследованный от системного класса `Object` через цепочку прототипов `Function.prototype`.

У этого объекта есть два ключевых внутренних метода, скрытых от разработчика:
*   **<code>&#91;&#91;Call&#93;&#93;</code>** — запускается, когда функция вызывается обычным образом: `myFunc()`.
*   **<code>&#91;&#91;Construct&#93;&#93;</code>** — запускается, когда функция вызывается через оператор `new`: `new MyClass()`.

Если у функции отсутствует метод <code>&#91;&#91;Construct&#93;&#93;</code> (как у стрелочных функций), попытка вызвать ее через `new` вызовет аппаратное исключение. Движок V8 оптимизирует вызовы функций в куче (Heap), создавая для них "скрытые классы" (Hidden Classes / Shapes), что позволяет компилятору JIT (Turbofan) генерировать сверхбыстрый машинный код для повторяющихся запусков.

### 2. Различия физики компиляции: Hoisting (Поднятие) деклараций против выражений
Процесс разбора кода V8 на этапе компиляции различает `FunctionDeclaration` и `FunctionExpression`:

```text
Фаза Компиляции (Парсинг области видимости):

1. При нахождении Function Declaration:
   V8 немедленно создает объект функции в куче и записывает ссылку в Environment Record.
   Скрипт: function sum(a,b) {}  ===>  Уже доступна для вызова.

2. При нахождении Function Expression (let sum = function(a,b) {}):
   V8 регистрирует переменную sum в Environment Record, но оставляет её неинициализированной (TDZ).
   Скрипт: const sum = ...       ===>  Вызов заблокирован до шага выполнения.
```

Благодаря этому `Function Declaration` полностью поднимается (hoisted) в памяти вместе со своим телом, в то время как `Function Expression` подчиняется стандартным законам лексической привязки переменных и недоступно в TDZ.

### 3. Детальный пошаговый разбор выполнения шаблона 1
1.  **Создание фрейма вызова (Stack Frame):** При вызове `addNewItemToCart(initialCartState, "Мышь", 1500)` в Call Stack создается новый изолированный кадр выполнения.
2.  **Запись аргументов:** Локальная переменная `cart` получает ссылку на адрес объекта `initialCartState` в куче. Локальные переменные `newItem` и `price` получают копии значений примитивов (`"Мышь"`, `1500`) в стеке.
3.  **Выполнение spread-оператора:** Инструкция `{ ...cart }` заставляет V8 выделить в куче новую ячейку памяти под новый объект и поверхностно скопировать туда свойства из старого адреса.
4.  **Разделение ссылок:** Копирование массива `[...cart.items, newItem]` создает новый массив в куче, отсекая связь с оригинальным массивом `items` из `initialCartState`. Изменение новой структуры не влияет на старую.
5.  **Возврат результата:** Новый объект возвращается наружу, а Stack Frame функции уничтожается.

### 4. Типичные ошибки и их решение

*   **Ошибка 1: Вызов функционального выражения (Function Expression) до его инициализации в коде**
    *   *Проблема:* Программа аварийно завершается с ошибкой `ReferenceError: Cannot access 'myFunc' before initialization` (для `const`/`let`) или `TypeError: myFunc is not a function` (для `var`).
    *   *Причина:* Попытка выполнить вызов функции, которая записана в переменную, до того как интерпретатор дошел до строки присвоения значения.
    *   *Решение:* Перенесите вызовы `Function Expression` строго ниже строк их инициализации или используйте `Function Declaration` для утилит, которые должны быть доступны глобально.

```javascript
// ПЛОХО (Попытка вызвать константное выражение в TDZ)
try {
  calculateValue(10); // ReferenceError
  const calculateValue = (x) => x * 2;
} catch (e) {
  console.error(e.message);
}

// ХОРОШО (Перенос инициализации наверх или использование Declaration)
const calculateValue = (x) => x * 2;
calculateValue(10); // Успешно выполнится
```

*   **Ошибка 2: Мутация переданных по ссылке объектов (грязные функции / Side Effects)**
    *   *Проблема:* Разработчик передает объект в функцию для изменения локального свойства, но случайно перезаписывает глобальное состояние приложения, что приводит к непредсказуемым багам рендеринга.
    *   *Причина:* Объекты передаются в функцию по ссылке. Любое изменение свойств (например, `obj.status = "done"`) внутри функции мутирует оригинальный объект в куче.
    *   *Решение:* Пишите чистые функции (Pure Functions), которые создают и возвращают новые копии объектов с помощью spread-оператора или `structuredClone()`.

```javascript
// ПЛОХО (Грязная функция изменяет оригинальный объект снаружи)
const user = { name: "Алексей", roles: ["user"] };
function addAdminRoleUnsafe(targetUser) {
  targetUser.roles.push("admin"); // Мутация оригинального массива в куче!
}
addAdminRoleUnsafe(user);

// ХОРОШО (Чистая функция возвращает новый иммутабельный объект)
function addAdminRoleSafe(targetUser) {
  return {
    ...targetUser,
    roles: [...targetUser.roles, "admin"] // Полное копирование вложенного массива
  };
}
const updatedUser = addAdminRoleSafe(user);
```

*   **Ошибка 3: Попытка вызова стрелочной функции в качестве конструктора через `new`**
    *   *Проблема:* Код падает с ошибкой `TypeError: ... is not a constructor`.
    *   *Причина:* Стрелочные функции оптимизированы для легковесной работы со стрелочным лексическим контекстом. У них отсутствует скрытый внутренний метод <code>&#91;&#91;Construct&#93;&#93;</code> и системное свойство `prototype`. Их физически нельзя вызвать через `new`.
    *   *Решение:* Для классов и функций-конструкторов используйте стандартные декларации `function` или современный синтаксис `class`.

```javascript
// ПЛОХО (Стрелочная функция не может быть конструктором)
const UserProfile = (name) => {
  this.name = name;
};
try {
  const profile = new UserProfile("Алексей"); // TypeError
} catch (e) {
  console.error(e.message);
}

// ХОРОШО (Использование классического конструктора или класса)
class UserProfileSafe {
  constructor(name) {
    this.name = name;
  }
}
const profile = new UserProfileSafe("Алексей"); // Успешно
```
